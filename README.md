# Esports Org Manager

A browser-based esports organisation management game. The current published game build is **Update 8.1**.

## Play

Open [index.html](./index.html) in a modern desktop browser. The game is a standalone HTML file and does not require a build step or package installation.

## Project status

- **Current build:** Update 8.1
- **Next planned update:** Update 8.2 — CS2 Movement & Navigation
- **Technology:** HTML, CSS, and JavaScript in a single-file browser game

## Development notes

The CS2 minimap movement is a known area for improvement. The planned Update 8.2 work is intended to replace unrealistic free-floating movement with map-aware routes and more believable tactical behaviour. This is a roadmap item, not a feature claimed as already fixed.

See [ROADMAP.md](./ROADMAP.md) for planned updates.
